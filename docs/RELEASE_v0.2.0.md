# ViralForecast v0.2.0

完整开源源码、可运行 CLI 与 Skill、本地视频理解、内置语音转写，以及平台导出 CSV 驱动的同类内容近期流量分析。

## 下载

- `viralforecast-skill-0.2.0.zip`：完整源码、测试、Schemas、文档和明确标记的模拟示例。
- `viralforecast-skill-0.2.0.zip.sha256`：ZIP 的 SHA256 校验和。
- `QUICKSTART.zh-CN.md`：中文安装与使用说明，ZIP 内也包含同一文档。

## 新增能力

- 无历史数据的透明启发式内容评估；有历史数据的时间回测、基线比较、预测区间与概率校准。
- 本地对象检测、短片段动作识别、视觉语义/文案匹配、可见表情线索分析和 Whisper 转写。
- 七个平台的 CSV 快照导入：相似内容检索、近期播放增量、样本相对热度、前后时间窗口走势和可测试的改进建议。
- JSON、Markdown、HTML 报告；趋势可单独运行或附加到视频分析。

## 使用

按附件中文说明建立 Python 虚拟环境、安装项目，并配置 FFmpeg/FFprobe。基础分析不需要付费 API。视觉/ASR 需额外安装 `.[understanding]` 并显式下载本地模型权重；权重不在源码 ZIP 中。

同类内容趋势使用用户有权访问的真实平台导出数据。至少两次快照才能衡量近期增长；单次快照不伪装成实时走势。平台内部推荐曝光量不可由普通播放数据推断，报告保留为空。相对热度只描述导入样本，不代表全平台；改进建议是待验证的实验，不保证流量提升。

本发布在四环境自动测试通过后打包。重量级模型在本地另有真实推理验证，常规 CI 无权重时明确跳过该测试。模拟数据仅用于软件验证，不能证明商业预测准确率。
