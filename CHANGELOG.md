# Changelog

## 0.2.0 — 2026-10-19

- Platform-export CSV snapshots for similar-content traffic, recent velocity, paired-window momentum and supported improvement experiments.
- Public-source ZIP, SHA256 and standalone Chinese quickstart attached through a test-gated GitHub Release workflow.

- Rewritten Chinese introduction and simplified homepage wording.
- Optional local object detection, temporal action recognition, CLIP scene/copy semantics and face-expression cues.
- Built-in CPU multilingual Whisper ASR, explicit model downloads, pinned snapshots and integrity checks.
- No-face/uncertain states and separate model provenance; statistical forecasting features remain unchanged.

## 0.1.0 — 2026-10-19

- Initial local CLI and reusable skill; seven configurable platform profiles.
- Explicitly heuristic metadata/text mode and optional cover/transcript features.
- Temporal ridge/median selection, split-conformal intervals, binned event calibration and abstention.
- Mature-label expanding-origin backtests, probability diagnostics and actual-error comparison.
- JSON, Markdown and escaped standalone HTML reports; Windows-first tests and CI configuration.

This is an experimental first release. No real-account accuracy claim or pretrained visual semantics model is included.
