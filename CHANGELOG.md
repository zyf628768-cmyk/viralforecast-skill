# Changelog

## 0.1.0 — 2026-10-19

- Initial local CLI and reusable skill; seven configurable platform profiles.
- Explicitly heuristic metadata/text mode and optional cover/transcript features.
- Temporal ridge/median selection, split-conformal intervals, binned event calibration and abstention.
- Mature-label expanding-origin backtests, probability diagnostics and actual-error comparison.
- JSON, Markdown and escaped standalone HTML reports; Windows-first tests and CI configuration.

This is an experimental first release. No real-account accuracy claim or pretrained visual semantics model is included.
